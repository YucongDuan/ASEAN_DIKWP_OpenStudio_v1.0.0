第一次使用

把整个ZIP解压到本机文件夹。点击上方按钮，或双击 OpenStudio_Offline.html。核心学习、检索、实验和作品导出均不需要联网、账号或模型密钥。

首页选择一个与你的问题接近的场景。它会创建作品草稿和仓库候选。进入“学习地图”理解方法，在“实践实验室”修改输入，最后把实验记录加入作品。

13种语言提供导航、常用操作与核心术语；12个深度学习单元和自测提供中文、英文、越南语。原始研究资料保留原文。

演示一个完整例子

选择跨境商品场景。对比1000 kg与1 tonne，看到“字符串不同”与“语义等价”的差别。把币种或交易目的改掉，再看关键差异。保存实验到作品，写清继承与修改，点击“导出开源作品ZIP”。

包内已有可运行范例：下载/打开学生示例ZIP。解压后运行：

python experiment.py
python -m unittest discover -s tests -v

使用账户、班级和教师反馈

在完整源码目录启动本地服务：

python server.py

浏览器进入 http://127.0.0.1:8765。学生可注册。教师账号由本机操作人员创建：

python server.py create-teacher --username teacher

教师创建课程和研究问题，将加入码给学生。学生自主提交作品快照后，教师即可阅读并反馈。离线草稿与账户草稿分开保存；可以通过导出与导入迁移。

从教学示例继承真实上游

作品包包含上游清单、角色与版本记录入口。平台的 scripts/upstream.py 可以锁定commit、下载源码、保留许可证与文件哈希；不自动运行下载代码。阅读上游README并确认接口后，将自己的适配代码放入新项目。
