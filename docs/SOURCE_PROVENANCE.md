# Source provenance

The seed lecture data is inherited from the user's `Duan_Guangxi_AI_Mesh98_Complete_Report.zip`, under its `source/` directory. The original JSON objects are retained as `data/mesh98_*.json`. They contain authored lecture notes, bibliographic and patent records, and repository-navigation annotations. The new catalogue normalizes these into a teaching schema while retaining source status.

The 483-entry candidate table originated from a historical 480-entry analysis plus three transparent-economy projects. It is presented alongside, not silently equated to, the author's dated official 483-repository directory. The author directory and PACT README were read through the GitHub connector for this task. This is selective source inspection, not an exhaustive code audit.

The institution's exchange record supports the educational relevance of cross-language commerce, agriculture and technical cooperation. It is not used as evidence of a completed institutional rename, adoption of this new software or a signed collaboration.

`data/sources.json` contains 107 source entries: 104 inherited report sources plus three platform-specific pointers. Original titles, publication dates, source types and verification notes remain visible in the library. The report notes remain Chinese; the new 12 teaching modules are available fully in Chinese, English and Vietnamese.

No third-party complete books or paper PDFs are bundled. Book covers in the app are typographic cards, not scans of publishers' artwork. No proprietary logo assets or font files are included. The new source code and new teaching prose are separately licensed; external materials retain their own terms.

Runtime code neither fetches external research pages nor calls any model or translation endpoint. The optional command-line metadata and source tools access GitHub only when explicitly invoked.
